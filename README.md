# Görev Takip Uygulaması

## Amaç
Bu proje, kullanıcıların görevlerini web sitesi üzerinden görüntüleyip yeni görev ekleyebilmesini sağlayan bir görev takip uygulamasıdır.

## Sayfalar
- index.html: Tanıtım sayfası.
- gorevler.html: Görevleri görüntüleme sayfası.
- gorev-ekle.html: Görev ekleme sayfası.

## Çalıştırma
index.html dosyasını bir tarayıcıda aç.
Menü bağlantılarıyla diğer sayfalara geç.

## Mevcut durum
Sayfadaki mevcut görevler örnek olarak eklenmiştir ve form henüz görev kaydetmemiştir.

## Kontrol
Sayfa bağlantılarını ve formun zorunlu alan uyarılarını dene.
