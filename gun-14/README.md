# Görev Takip Uygulaması (React + Typescript)

## Amaç
Görev ekleme, tamamlama, silme, arama ve duruma göre filtreleme.

## Bileşenler
- GorevFormu: yeni görev ekler
- GorevFiltresi: arama ve durum filtresi
- GorevListesi: görevleri listeler
- GorevKarti: tek bir görevi gösterir

## Çalıştırma
npm install
npm run dev
